# Checklist de diseño — Hotel Miranda

## Tokens

- [ ] Color, tipografía, espaciado, radios y sombras aplicados.
- [ ] Modo oscuro coherente en admin.
- [ ] Contraste AA.

## Responsive

- [ ] 320, 375, 768, 1024, 1280, 1440.
- [ ] Sin scroll horizontal no intencionado.
- [ ] Textos ES/EN sin cortes.

## Componentes

- [ ] Default, hover, focus, active, disabled.
- [ ] Loading, skeleton, empty, error.
- [ ] Formularios con labels y mensajes de error.
- [ ] Diálogos con foco atrapado y cierre accesible.

## Motion

- [ ] Duraciones 150/250/400 ms.
- [ ] `prefers-reduced-motion`.
- [ ] Sin animaciones que bloqueen interacción.

## QA visual

- [ ] Capturas por breakpoint.
- [ ] Comparación contra especificación.
- [ ] Aprobación del diseñador.
