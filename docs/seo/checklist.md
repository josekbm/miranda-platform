# Checklist SEO — Hotel Miranda

## Por página

- [ ] Title único (50-60 caracteres).
- [ ] Meta description única (140-160).
- [ ] Un solo H1.
- [ ] Jerarquía H2/H3.
- [ ] Canonical.
- [ ] `hreflang` recíproco + `x-default`.
- [ ] Open Graph y Twitter Cards.
- [ ] Alt text descriptivo.
- [ ] Enlazado interno.
- [ ] Datos estructurados válidos.
- [ ] URL limpia y estable.
- [ ] Contenido único, no traducción automática.

## Técnico

- [ ] SSR o prerender para contenido crítico.
- [ ] Sitemap con alternates.
- [ ] `robots.txt`.
- [ ] 404 personalizado.
- [ ] Redirects 301.
- [ ] Core Web Vitals en verde.
- [ ] Sin contenido duplicado entre idiomas.
- [ ] Search Console y Bing Webmaster.
- [ ] Analítica con eventos.

## Local

- [ ] NAP consistente.
- [ ] `Hotel` schema con dirección, geo y teléfono.
- [ ] Google Business Profile.
- [ ] Mapa.
- [ ] Reseñas/testimonios.
